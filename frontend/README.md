# Front-end = React.js + TypeScript

### Dependencies used:

1. vite = npm create vite@latest
2. React Router = npm install react-router-dom
3. Tailwind CSS = npm install tailwindcss @tailwindcss/vite
4. Axios = npm install axios
5. React Icons = npm install react-icons --save
